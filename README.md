# The Oberdorfer Team — Concept 1

Brand book No. 01 for **The Oberdorfer Team**, a residential real-estate team at **REWAP Brokerage LLC**, Central Massachusetts.

**Live:** https://cptnope.github.io/The-Oberdorfer-Team-Concept-1/

The concept is "The Quarterly": the brand presented like an independent architecture magazine printed on New England stock (shutter green, plaster, oak, with brick as spot ink). The book covers purpose, audience, voice, identity, typography, color, photography, layout, interface (listings, search, property detail, towns, buying and selling), motion, accessibility and the team-to-brokerage affiliation system.

- `DESIGN.md` is the design system and the spec for the WordPress block theme.
- `PRODUCT.md` is the product and brand context.
- `CLAUDE.md` explains the repo layout and rules for working on it with Claude.

All photographs are credited Unsplash samples and all listings are illustrative; see chapter 07 for the replacement shot list.
