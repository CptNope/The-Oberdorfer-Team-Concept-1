Lead handoff to Follow Up Boss

Every form and save on the website becomes a Follow Up Boss event, with the person, the house and the campaign attached. This page is the spec the WordPress build follows.

Try it on a listingOpen-house sign-in

Every site form shows the exact event it would send, and sends nothing. Field names follow Follow Up Boss's Events API as documented in October 2026.

How a lead travels

The API key never reaches the browser.

  1. The visitor submits a formThe site checks it first: a first name, and an email or a phone number. Follow Up Boss matches people by email or phone, so one of them is required.
  2. The browser posts to the team's own serverA WordPress REST endpoint on the team's hosting (for example /wp-json/oberdorfer/v1/lead) receives the form, never the Follow Up Boss key.
  3. The server sends the eventPOST https://api.followupboss.com/v1/events with HTTP Basic auth (the API key as the username, blank password) and the X-System and X-System-Key headers the site receives when it is registered as a system.
  4. Follow Up Boss files itIt finds the person by email or phone or creates them, attaches the event, and runs the lead flow for the source: assignment, notifications and action plans.
  5. The server records the answer201 means a new person, 200 an existing one updated, 204 that the source's lead flow is archived and ignored. Failed requests are queued and retried; the visitor sees their confirmation either way.

Set up in Follow Up Boss

What the team, REWAP and the developer each settle before launch.

  • Register the site as a system. Follow Up Boss asks anyone sending data for a customer to register; registration issues the X-System-Key that goes with X-System: OberdorferTeamSite.
  • Create the API key. From Admin → API in the account that should own website leads. It has that user's full privileges, so it lives only in the server's environment settings.
  • Choose the source name. The site's domain without "www". A lead flow rule for that source decides assignment (Brandon, Kait, or a rotation) and which action plan starts.
  • Write the action plans. At least one each for Property Inquiry, Seller Inquiry and Visited Open House, in the brand book's voice.
  • Add every agent as a user with the same full name the website uses, so person.assignedTo matches. A new agent is added here when their page is added to the site.
  • Create the custom field "Brokerage" (customBrokerage), and agree the tag list above so smart lists and reports can use it.
  • Confirm the consent wording with REWAP's principal broker, and finish A2P 10DLC registration before relying on text follow-up; US business texting goes through it.
  • Retire the old routing. If the BoldTrail/kvCORE site or a lead service also sends to Follow Up Boss, give each its own source so nothing arrives twice under one name.
  • Test end to end with a test contact: expect 201 the first time and 200 the second, then check that the lead flow, tags and action plan ran.
